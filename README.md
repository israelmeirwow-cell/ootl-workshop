# יציאה מהלופ: דף נחיתה לסדנה

דף ההרשמה לסדנה של יציאה מהלופ (4 שעות, תל אביב, 25 מקומות).
בנוי על אותה מערכת עיצוב של האתר הראשי (`out_of_the_loop_vallora/`): שמנת, דיו ואדום הלופ, Heebo, ו־Frank Ruhl Libre ללוגו ולציטוט. קו הלופ עם הנקודה האדומה עובר לאורך כל הדף.
הטקסטים הם מהבריף, מילה במילה (`src/content.ts`).

## העלאה לאוויר (GitHub Pages)
האתר באוויר בכתובת https://israelmeirwow-cell.github.io/ootl-workshop/ (המאגר israelmeirwow-cell/ootl-workshop מכיל רק את הקבצים הבנויים).
כדי להעלות גרסה חדשה:
```bash
npm run build:gh
```
ואז מעתיקים את התוכן של `dist/` לתוך עותק של המאגר, עושים commit ו-push ל-main. GitHub מעדכן את האתר תוך דקה בערך.

## הרצה
```bash
npm install
npm run dev      # תצוגה מקומית
npm run build    # בונה ל-dist/, את התיקייה הזו מעלים לאחסון
```

## מה צריך להשלים לפני שמעלים (הכל ב-`src/config.ts`)
בזמן `npm run dev` כל פרט חסר מסומן בדף במסגרת אדומה מקווקוות. בגרסה שעולה לאוויר פרט חסר פשוט לא מוצג.

| מה | איפה ב-config.ts |
| --- | --- |
| תאריך ושעות | `event.date`, `event.hours` |
| שם השותפה, הטקסט שלה | `team.partnerName`, `team.partnerText` |
| טקסטים מאושרים של אלון ומרים, שם המשפחה של מרים | `team.alonText`, `team.miriamText`, `team.miriamSurname` |
| תמונות אמיתיות (רז והשותפה יחד לראש הדף, השותפה, אלון, מרים). התמונה של רז כבר בפנים | לשים ב-`public/images/` ולכתוב את הנתיב ב-`photos` |
| קישור לתשלום | `payment` (ראו למטה) |
| קישור לקבוצת הוואטסאפ | `whatsappGroupUrl` |
| גוגל שיט: נרשמים, מיילים לצוות ומונה המקומות | `leadsEndpoint`, `seats.remoteUrl` (ראו למטה) |
| פיקסל מטא ופיקסל טיקטוק | `pixels.metaId`, `pixels.tiktokId` |
| האינסטגרם של רז (כבר מוגדר: @raz_bezek_) | `team.razInstagram` |
| כתובת האתר (להודעת השיתוף) | `siteUrl` |

## מי נרשם, קוד כניסה ומייל לרז
1. מי שנכנס ממלא את הפרטים (כולל מייל) ועובר ישר לתשלום בביט.
2. אחרי התשלום לוחצים "סיימתי לשלם". במסך התודה מופיע קוד כניסה של 6 תווים, ובאותו רגע:
   - הנרשם מקבל מייל עם קוד הכניסה (מציגים אותו בכניסה לסדנה);
   - רז (וכל מי שברשימה) מקבלת מייל עם כל מה שהנרשם מילא: תחום, מה ניסה, מה המצב שלו, הרעיון, הסכום והקוד.
3. ביט לא מודיע לאתר שהכסף נכנס, אז בודקים באפליקציה ומסמנים ✓ בעמודה "שולם" בגיליון. רק שורות עם ✓ נספרות כמקום שנמכר, והמחיר בדף עולה לפיהן.
4. כל ערב ב-20:00 יוצא מייל סיכום: מי נרשם היום, ומי מילא טופס ועוד לא דיווח על תשלום.

המיילים יוצאים מחשבון הגוגל שמחבר את הסקריפט, והחשבון הזה תמיד מקבל את מייל הסיכום. כתובות נוספות: השורה `NOTIFY_EMAILS` בראש `apps-script/Code.gs`.
תאריך, מקום וקישור לקבוצה למייל של הנרשם: `EVENT_DATE`, `EVENT_PLACE`, `GROUP_URL` באותו קובץ.
גיבוי: כל הרשמה וכל דיווח תשלום נשמרים גם ב-Netlify (בלוח הבקרה של האתר ← Forms), גם לפני שהגיליון מחובר.

### חיבור (פעם אחת, בערך 5 דקות, מהחשבון של גוגל שממנו ייצאו המיילים)
1. פותחים גיליון חדש בגוגל שיטס (sheets.new) ונותנים לו שם, למשל "נרשמים לסדנה".
2. בתפריט: **תוספים ← Apps Script**. מוחקים את מה שכתוב שם, מדביקים את כל התוכן של `apps-script/Code.gs`, ושומרים (אייקון הדיסקט).
3. למעלה בוחרים את הפונקציה **setup** ולוחצים **הפעלה**. גוגל תבקש הרשאות:
   "בדיקת הרשאות" ← בוחרים את החשבון ← "מתקדם" ← "מעבר אל ... (לא בטוח)" ← "התרה".
   (זה המסך הרגיל לסקריפט פרטי שלך, הוא לא עובר דרך אף אחד אחר.)
4. אפשר לבחור את הפונקציה **testEmail** וללחוץ הפעלה, כדי לראות שמייל בדיקה מגיע.
5. **פריסה ← פריסה חדשה** ← סוג: **אפליקציית אינטרנט**. "הפעלה בתור": אני. "למי יש גישה": **כל אחד**. לוחצים "פריסה" ומעתיקים את הכתובת שנגמרת ב-`/exec`.
6. את הכתובת שולחים לי, או מדביקים ב-`src/config.ts` בשני מקומות: `leadsEndpoint` וגם `seats.remoteUrl`. ואז `npm run build`.

אם משנים את הקוד בסקריפט אחר כך: פריסה ← ניהול פריסות ← עריכה ← גרסה חדשה (הכתובת נשארת אותה כתובת).

## תשלום בביט
לבחירה, או שניהם יחד:
- **הקישור האישי מביט:** באפליקציית ביט יש קוד QR אישי שאפשר לשתף כקישור. מי שלוחץ עליו מגיע ישר לתשלום אליך, בלי להקליד מספר. שמים אותו ב-`payment.bitUrl`. הסכום לא נכנס לבד, אז הדף מציג "בביט מקלידים את הסכום: 49 ש״ח". במחשב הדף מציג גם QR לסריקה מהטלפון.
- **מספר ביט:** שמים ב-`payment.bitPhone`. הדף מציג את המספר, את הסכום וכפתור להעתקת המספר.

אחרי התשלום הנרשם לוחץ "סיימתי לשלם", עובר למסך התודה, והצוות מקבל מייל לבדוק בביט ולסמן ✓.
אפשר גם קישור של חברת סליקה עם ביט (Grow, Morning, PayMe): שמים אותו ב-`payment.bitUrl` עם `{amount}` במקום הסכום, ומבקשים מהחברה להחזיר אחרי תשלום לכתובת `https://<האתר>/?paid=1`.
תשלום בכרטיס אשראי (לא חובה): `payment.cardUrl`.

## שיתוף בוואטסאפ ובאינסטגרם
תמונת השיתוף נמצאת ב-`public/og.png` (1200×630). אחרי שיש כתובת קבועה, כדאי לשנות ב-`index.html` את `og:image` לכתובת מלאה, למשל `https://<האתר>/og.png`, כי וואטסאפ לא תמיד קורא נתיב יחסי.

## מבנה הדף
פתיח (הקו נכתב ומגיע לנקודה האדומה) · מכירים את זה? (הקטע הכהה, הלופ מסתבך בגלילה ואז מתיישר) · שלושה מצבים · למה הקמנו (ציטוט של רז) · השיטה (המעגל הטוב: הנקודה רצה בין ארבעת השלבים) · לפני ואחרי (קו מחיקה אדום) · לוח הזמנים (שעון של 4 שעות במחשב, אקורדיון בטלפון) · הצוות · מה מקבלים (כרטיס כניסה עם ספח מחיר) · מדרגות המחיר (המקומות כריבועים) · שאלות · קריאה אחרונה · טופס → תשלום → תודה.
בטלפון יש פס הרשמה דביק בתחתית, שנעלם כשהטופס על המסך.
